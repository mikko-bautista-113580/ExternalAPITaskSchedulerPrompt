The problem · Why this matters

One endpoint is a lot of careful, repetitive work.

Every Admissions GET endpoint is a vertical slice built to the microservices architecture standard. Done by hand, each one is hours of pattern-matching before a single new idea is written:

  • Find the latest reference PR and reverse-engineer the full file set it ships
  • Controller, Query/Handler, Sieve-projected DTO, EF entity + context wiring
  • Confirm columns against the real SQL schema — don't break production writers
  • Unit tests, API integration tests, fakers, helpers
  • Generate and approve verified snapshots, then drive the build to green

The tax: it's not the hard part of the job — it's the same shape every time. It's easy to skip the API-test tier under deadline, and the pattern drifts between developers.

So the completeness and consistency depend on who had time that week.
